# Proposal phase (before this thesis)

Topic finding, topic understanding, and the initial literature research took
place before this thesis, as part of the accepted proposal, between October 2025
and February 2026. That work ran in ChatGPT (GPT-5 and GPT-5.2). The topic itself
came from the DIMA topic list; the choice of RocksDB over LMDB as the storage
backend followed the advisor's recommendation.

ChatGPT publishes individual conversations rather than whole projects, so there
is no public link to the project. The conversations are archived here instead,
as browser captures with one entry file each:

| Phase | Folder |
|-------|--------|
| 1. Finding and nailing down the topic | [`01-topic-finding/`](01-topic-finding) |
| 2. Understanding the topic | [`02-understanding-topic/`](02-understanding-topic) |
| 3. Literature research | [`03-literature-research/`](03-literature-research) |
