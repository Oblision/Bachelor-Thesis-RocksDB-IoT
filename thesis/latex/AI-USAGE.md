# AI Tool Usage

In line with TU Berlin DIMA requirements for documenting AI tool use, every
substantive conversation with an AI tool during the bachelor's thesis is
committed publicly to the out-of-core NebulaStream repository:

<https://github.com/Oblision/nebulastream-Out-of-Core-Stream-Processing/tree/main/docs/ai-usage>

The structure mirrors the eight phases in `misc/declaration-of-aids.tex`:

| Phase | Folder URL |
|-------|------------|
| 1. Finding and nailing down the topic | <https://github.com/Oblision/nebulastream-Out-of-Core-Stream-Processing/tree/main/docs/ai-usage/01-topic-finding> |
| 2. Understanding the topic | <https://github.com/Oblision/nebulastream-Out-of-Core-Stream-Processing/tree/main/docs/ai-usage/02-understanding-topic> |
| 3. Literature research | <https://github.com/Oblision/nebulastream-Out-of-Core-Stream-Processing/tree/main/docs/ai-usage/03-literature-research> |
| 4. Implementing the prototype | <https://github.com/Oblision/nebulastream-Out-of-Core-Stream-Processing/tree/main/docs/ai-usage/04-implementing-prototype> |
| 5. Testing the prototype | <https://github.com/Oblision/nebulastream-Out-of-Core-Stream-Processing/tree/main/docs/ai-usage/05-testing-prototype> |
| 6. Planning the thesis | <https://github.com/Oblision/nebulastream-Out-of-Core-Stream-Processing/tree/main/docs/ai-usage/06-planning-thesis> |
| 7. Writing the thesis | <https://github.com/Oblision/nebulastream-Out-of-Core-Stream-Processing/tree/main/docs/ai-usage/07-writing-thesis> |
| 8. Revising the thesis | <https://github.com/Oblision/nebulastream-Out-of-Core-Stream-Processing/tree/main/docs/ai-usage/08-revising-thesis> |

Each entry inside a phase folder is one conversation, named
`YYYY-MM-DD-short-topic.md`, and follows the schema in `_template.md` of the
same folder: YAML frontmatter, goal, outcome, verbatim prompt, full transcript.

The `Link to Prompts` column in `misc/declaration-of-aids.tex` cites the same
URLs.
